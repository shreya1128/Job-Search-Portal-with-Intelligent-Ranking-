## 2. Experimental Rigour & Verification Standards

To satisfy academic project evaluation guidelines:
1. **Zero Fabrication**: All reported metrics (P@K, nDCG, Hit@10, PageRank iterations) are generated directly from execution scripts and stored outputs.
2. **Explicit Labeling of Synthetic Data**:
   All 300 generated test users and 9,124 user interaction rows are marked with `is_synthetic = 1` in the database and explicitly tagged in outputs to avoid misleading evaluation.
3. **Reproducibility**:
   Every stage has an automated verification script (`verify_phase7.py`, `evaluate_ir.py`, `evaluate_recommenders.py`) that can be executed independently.
